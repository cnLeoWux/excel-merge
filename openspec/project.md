# 项目背景

## 项目目的

Excel Merge Tool 是一个基于 Python 的应用程序，用于根据特定的业务逻辑匹配两个 Excel/CSV 文件。该工具从一个 Excel 文件中处理订单数据，并将其与另一个 Excel 文件中的支付/退款详情进行匹配，以更新 "支付手续费" 列。主要目的是根据复杂的业务规则自动匹配订单数据与支付/退款数据，并直接修改原始订单文件。

## 技术栈

- Python 3.7+
- pandas>=1.3.0
- openpyxl>=3.0.0
- xlrd>=2.0.0
- pathlib（用于文件路径操作）
- re（用于正则表达式）

## 项目约定

### 代码风格

- 列名使用业务需求中指定的中文（例如："订单号"、"商户订单号"、"支付手续费"）
- 代码优先考虑精确匹配要求，而非泛化
- 函数参数和返回值使用类型提示
- 提供详细日志以展示匹配过程
- 遵循 PEP 8 Python 风格指南

### 架构模式

- 关注点分离：主执行逻辑位于 excel_merge.py，工具函数位于 utils.py，CLI 功能位于 cli.py
- 基于 Pandas 的数据处理，实现高效的 Excel/CSV 操作
- 文件处理支持多种编码（UTF-8、GBK、GB2312、Latin-1、UTF-8-sig）
- 模块化方法，具有专门用于读取文件、处理数据和写入结果的函数

### 测试策略

- 针对单个函数的单元测试，特别是匹配逻辑和数据处理函数
- 集成测试，确保完整工作流正常运行
- 验证脚本，用于验证输入/输出文件格式和数据完整性
- 针对各种文件格式和编码场景的错误处理测试

### Git 工作流

- 新功能开发使用特性分支
- 主分支用于稳定发布
- 提交信息应描述对匹配逻辑、文件处理或错误修复所做的更改
- 重大更改需通过拉取请求并进行代码审查

## 领域上下文

- 启动程序后列出ExcelForHandel目录下所有文件供选择，分别选择第一个文件和第二个文件
- **订单-支付匹配**：首先，使用前 20 个字符将第一个文件中的 "订单号" 与第二个文件中的 "商户订单号" 进行匹配
- 如果订单号少于 20 个字符，则将第一个文件中的 "外部订单号" 与第二个文件中 "商品名称" 最后一个 "-" 后的部分进行匹配
- 基于 P 编号模式的替代匹配（例如：P 后跟数字）
- **订单类型确定**："订单金额" 为正（> 0）的订单是常规订单（正单），使用 "收费" 业务类型；"订单金额" 为负（< 0）的订单是退款订单（退单），使用 "退费" 业务类型；"订单金额" 为零（= 0）的订单，"支付手续费" 设置为 0.0
- **支付金额分配**：对于常规订单（正单）："支付手续费" = 匹配支付记录中的 "支出金额（-元）"；对于退款订单（退单）："支付手续费" = 匹配支付记录中的 "收入金额（+元）"
- CSV 文件可能包含注释（以 # 开头的行被忽略，第一个非注释行用作标题）
- 直接修改原始订单文件，而不是创建新文件

## 重要约束

- 必须处理具有多种编码的文件（UTF-8、GBK、GB2312、Latin-1、UTF-8-sig）
- 订单号必须保留为字符串，以防止 Excel 的数字转换问题
- 必须正确处理订单号和金额中的 NaN 值
- 需要直接修改原始文件（不要创建新文件）
- 支持 Excel（.xlsx、.xls）和 CSV 文件格式
- 文件应位于当前目录或 "ExcelForHandel" 子目录中
